物質の構成

この単元の得点源は「純物質か混合物か」「元素か単体か」「どの分離法を使うか」の3つの判別です。

物質の分類

分類 定義 例
単体（純物質） 1種類の元素からなる O₂、O₃、Fe、C（ダイヤモンド）、N₂（液体窒素）、Hg
化合物（純物質） 2種類以上の元素からなる H₂O（氷水も）、CO₂（ドライアイス）、NaCl、NH₃
混合物 2種類以上の純物質が混ざったもの 空気、海水、石油、牛乳、塩酸、アンモニア水、食塩水、合金、ガラス
  • 純物質は融点・沸点・密度が一定。混合物は組成により変わる。
  • ひっかけ注意：塩酸は「HClの水溶液」なので混合物。氷水は状態が違うだけでH₂Oのみ → 純物質。

蒸留装置のチェックポイント（実験図の正誤問題で頻出）

  • 温度計の球部は枝付きフラスコの枝の付け根の高さ（蒸気の温度を測る）。
  • 沸騰石を入れる（突沸防止）。液量はフラスコの半分以下。
  • リービッヒ冷却器の冷却水は下から入れて上から出す（冷却器内を水で満たすため）。
  • 受け器（三角フラスコ）は密栓しない（圧力が上がって危険）。アルミ箔などで軽くふたをする。

物質の三態と熱運動

  • 固体 → 液体：融解、液体 → 固体：凝固、液体 → 気体：蒸発、気体 → 液体：凝縮、固体 → 気体：昇華、気体 → 固体：凝華。
  • 純物質を加熱すると、状態変化（融解・沸騰）の間は温度が一定。加えた熱は粒子間の引力を断ち切るのに使われる。
  • 粒子は温度に応じて熱運動をしている。拡散は熱運動による。
  • 絶対温度 T [K] = t [℃] + 273。絶対零度（0 K = −273℃）で熱運動は最も穏やかになる。
  • 状態変化・溶解は物理変化（物質そのものは変わらない）。燃焼・中和・さびは化学変化。

原子の構造と周期表

原子番号1〜20の電子配置を書けること、そしてイオン化エネルギー・原子半径・電気陰性度の周期的な傾向をグラフから読めることが満点の前提です。

原子の構造

粒子 場所 電荷 質量
陽子 原子核 +1 約1（基準）
中性子 原子核 0 陽子とほぼ同じ
電子 原子核の周り −1 陽子の約1/1840
  • 原子番号 = 陽子の数（＝原子では電子の数）。質量数 = 陽子の数 + 中性子の数。
  • 原子の直径は約10⁻¹⁰ m、原子核は約10⁻¹⁵〜10⁻¹⁴ m（原子の約1/10万〜1/1万）。
  • 原子の質量はほぼ原子核の質量。電子の質量は無視できるほど小さい。

同位体と放射性同位体

  • 同位体：原子番号（陽子数）が同じで中性子数（質量数）が異なる原子。化学的性質はほぼ同じ。例：¹H・²H（D）・³H（T）、¹²C・¹³C・¹⁴C、³⁵Cl・³⁷Cl。
  • 放射性同位体：原子核が不安定で放射線を出して別の原子核に変わる（壊変）。¹⁴Cの半減期は約5730年 → 遺跡などの年代測定に利用。
  • 半減期 T のとき、時間 t 後に残る割合は (1/2)^(t/T)。11460年後なら1/4。

イオンの電子数

  • 陽イオン（価数 n）の電子数 = 原子番号 − n、陰イオンの電子数 = 原子番号 + n。
  • 例：Mg²⁺ は 12 − 2 = 10個、S²⁻ は 16 + 2 = 18個。
  • 同じ電子配置のイオンは原子番号が大きいほど小さい（陽子が多く電子を強く引く）。
    • Ne型：O²⁻ ＞ F⁻ ＞ Na⁺ ＞ Mg²⁺ ＞ Al³⁺
    • Ar型：S²⁻ ＞ Cl⁻ ＞ K⁺ ＞ Ca²⁺

周期表

  • 縦の列＝族（1〜18族）、横の行＝周期（第1〜第7周期）。同族元素は価電子数が同じで性質が似る。

化学結合

結合の種類は「金属＋非金属＝イオン結合、非金属同士＝共有結合、金属同士＝金属結合」で判定し、結晶の性質（融点・電気伝導性・硬さ）までセットで答えられるようにします。

結合と結晶の総まとめ

結晶 結合する元素 粒子間の結合 融点 電気伝導性 硬さなど 例
イオン結晶 金属＋非金属 イオン結合（静電気的引力） 高い 固体×、融解液・水溶液〇 硬いがもろい（たたくと割れる＝へき開） NaCl、CaO、CaCO₃、NH₄Cl
共有結合の結晶 非金属（C、Si） 共有結合のみで巨大な立体網目 非常に高い ×（黒鉛のみ〇） 非常に硬い（黒鉛はやわらかくはがれやすい） ダイヤモンド、黒鉛、Si、SiO₂（石英・水晶）
分子結晶 非金属 分子内は共有結合、分子間は分子間力 低い × やわらかい、昇華しやすいものあり 氷、ドライアイス、ヨウ素、ナフタレン
金属結晶 金属 金属結合（自由電子） 一般に高い（Hgは液体） 〇（固体でも） 展性・延性、金属光沢、熱伝導性 Fe、Cu、Al、Na
  • NH₄ClやNH₄NO₃は金属を含まないがイオン結晶（NH₄⁺がイオン）。
  • 電気伝導性の大きい金属：Ag ＞ Cu ＞ Au ＞ Al。電線にはCu・Alを使う。
  • ガラスやアモルファスシリコンは粒子の配列が不規則な**非晶質（アモルファス）**で、一定の融点をもたない。

イオン結合と組成式

陽イオンと陰イオンの電荷の総和が0になる比で組成式を書きます。読み方は陰イオン → 陽イオンの順（例：塩化ナトリウム）。

水酸化物イオン OH⁻ 炭酸イオン CO₃²⁻
硝酸イオン NO₃⁻ リン酸イオン PO₄³⁻

例：硫酸アルミニウム Al₂(SO₄)₃、リン酸カルシウム Ca₃(PO₄)₂、炭酸水素ナトリウム NaHCO₃。

  • 原子価（価標の数）：H 1、Cl 1、O 2、N 3、C 4。
  • 共有電子対：結合に使われている電子対。非共有電子対：結合に使われていない電子対。

  • 極性分子：結合に極性があり、分子の形で打ち消されない（H₂O、NH₃、HCl）。無極性分子：同じ原子同士の結合、または形が対称で極性が打ち消される（CO₂、CH₄、CCl₄）。

配位結合

  • 一方の原子の非共有電子対を、もう一方が共有して生じる共有結合。
  • NH₃ + H⁺ → NH₄⁺（正四面体）、H₂O + H⁺ → H₃O⁺（三角錐）。
  • 生成後のNH₄⁺の4つのN−H結合は区別できない（性質がまったく同じ）。
  • 金属イオンに非共有電子対をもつ分子・イオンが配位結合したものを錯イオンという（例：[Cu(NH₃)₄]²⁺ 深青色）。

分子間力と沸点

  • 分子間力（ファンデルワールス力など）は、構造が似た分子なら分子量が大きいほど強い → 沸点が高い。例：F₂ ＜ Cl₂ ＜ Br₂ ＜ I₂、CH₄ ＜ SiH₄ ＜ GeH₄。
  • 分子量が同程度なら極性分子のほうが沸点が高い。
  • 水素結合：電気陰性度の大きいF・O・Nに結合したH原子が、別の分子のF・O・N原子と引き合う。HF、H₂O、NH₃は分子量が小さいのに沸点が異常に高い。
  • 結合の強さ：共有結合 ＞ 水素結合 ＞ ファンデルワールス力。

高分子化合物（概要）

  • 小さな分子（単量体）が多数結合した巨大分子（重合体）。
  • 付加重合：ポリエチレン（エチレンから）、ポリ塩化ビニル、ポリスチレン。
  • 縮合重合：ポリエチレンテレフタラート（PET）、ナイロン。

物質量と濃度

すべての計算は「まず mol に直す」が原則です。質量・粒子数・気体の体積・濃度はすべて mol を経由して換算します。

原子量・分子量・式量

  • 基準：¹²C原子1個の質量を12としたときの相対質量。
  • 原子量＝各同位体の相対質量 × 存在比 の平均。例：Cl（³⁵Cl 75%、³⁷Cl 25%）→ 35 × 0.75 + 37 × 0.25 = 35.5。
  • 分子量：分子を構成する原子の原子量の総和（H₂O = 18）。式量：イオン結晶・金属・イオンなど分子をもたない物質に使う（NaCl = 58.5）。
  • 電子の質量は無視できるので、Na⁺の式量はNaの原子量と同じ23。

物質量（mol）の換算

1 mol = 6.0 × 10²³ 個（アボガドロ定数 Nᴀ = 6.0 × 10²³ /mol）。

n [mol] =w [g]M [g/mol]=N [個]6.0 × 10²³=V [L]22.4 [L/mol]（標準状態の気体）
  • モル質量 = 原子量・分子量・式量に g/mol をつけたもの。
  • 22.4 L/mol は0℃・1.013 × 10⁵ Pa の気体にだけ使える。液体・固体や25℃の気体には使えない（問題文の条件を必ず確認）。
  • 気体の分子量 = 22.4 × 密度［g/L］（標準状態）。
  • 同温・同圧では気体の種類に関係なく体積比 = 物質量比（アボガドロの法則）。
  • 平均分子量：空気（N₂ : O₂ ≒ 4 : 1）= 28 × 0.8 + 32 × 0.2 ≒ 28.8 → 分子量が28.8より大きい気体は空気より重い（CO₂、Cl₂など）。

化学反応式と量的関係

係数の比 = 物質量の比 =（同温同圧の気体なら）体積の比です。質量の比ではない点が最大のひっかけです。

係数の決め方

  1. 最も複雑な物質の係数を1とおく。
  2. その物質に含まれる原子から順に、両辺で原子数をそろえる（O・Hは後回し）。
  3. 分数が出たら全体を整数倍する。

例：プロパンの燃焼　C₃H₈ + 5O₂ → 3CO₂ + 4H₂O

複雑な場合は未定係数法（各係数をa、b、c…とおいて原子ごとに方程式を立てる）。

量的関係の解き方（4ステップ）

  1. 反応式を書く。
  2. 与えられた量を mol に直す。
  3. 係数比で求めたい物質の mol を出す。
  4. 求められた単位（g、L、個）に直す。

過不足のある反応

  • 両方の反応物を mol にし、係数で割った値が小さいほう（限定反応物）が全部反応する。生成物の量は限定反応物で決まる。
  • 反応後に残る物質（未反応の反応物）も答えられるように表を書く。

グラフ問題の読み方

一方の量を一定にして他方を増やすと、生成量のグラフは折れ線になります。

  • 折れ点 = 2つの反応物がちょうど過不足なく反応した点。
  • 折れ点より左：加えた物質がすべて反応（生成量は加えた量に比例）。
  • 折れ点より右：もう一方が尽きて生成量は一定。
  • 折れ点の座標から、濃度・原子量・係数比を逆算させる問題が頻出（共通テスト形式演習 問7参照）。

混合物の反応

成分ごとに未知数（x mol、y mol）をおき、「全体の量」と「生成物の量」で連立方程式を立てます。

例：CH₄ x mol と C₂H₆ y mol の混合気体0.30 molを完全燃焼させると CO₂ 0.40 molが生じた → x + y = 0.30、x + 2y = 0.40 より x = 0.20、y = 0.10。

気体の体積変化

2CO + O₂ → 2CO₂ のように反応で気体の分子数が変わると、全体積も変わります。同温同圧なら体積をそのまま mol のように係数比で計算してよい。

酸と塩基

中和の量的関係は「酸の価数 × 酸の物質量 = 塩基の価数 × 塩基の物質量」で、酸・塩基の強弱には関係しません。強弱が効いてくるのは pH・指示薬・塩の液性です。

酸・塩基の定義

  • HCl + H₂O → H₃O⁺ + Cl⁻ では H₂Oは塩基。
  • NH₃ + H₂O ⇄ NH₄⁺ + OH⁻ では H₂Oは酸。
  • 同じ物質でも反応によって酸にも塩基にもなる。

電離度と水素イオン濃度

  • 電離度 α = 電離した酸（塩基）の物質量 ÷ 溶かした酸（塩基）の物質量。強酸・強塩基は α ≒ 1。
  • [H⁺] = 酸のモル濃度 × 価数 × α、[OH⁻] = 塩基のモル濃度 × 価数 × α。
  • 水のイオン積：[H⁺][OH⁻] = 1.0 × 10⁻¹⁴ (mol/L)²（25℃）。
  • pH = −log₁₀[H⁺]。[H⁺] = 1.0 × 10⁻ⁿ のとき pH = n。25℃で中性は pH 7。
  • 塩基性溶液は [OH⁻] から pOH を出し、pH = 14 − pOH。

希釈と pH

  • 強酸を10倍に薄めると pH は1大きくなる（pH 2 → 3）。強塩基を10倍に薄めると pH は1小さくなる。
  • ひっかけ注意：酸をいくら薄めても pH は7を超えない（7に近づくだけ）。
  • 弱酸は薄めると電離度が大きくなるため、10倍に薄めても pH の増加は1より小さい。

酸化還元

酸化還元の量的関係は「酸化剤が受け取る電子の物質量 = 還元剤が失う電子の物質量」です。半反応式を自分で組み立てられれば、暗記量は大きく減ります。

  • 酸化剤＝相手を酸化し、自身は還元される物質。還元剤＝相手を還元し、自身は酸化される物質。

  4. 単原子イオンは価数がそのまま酸化数（Na⁺は+1、Cl⁻は−1）。化合物中のアルカリ金属は+1、2族は+2。

酸化還元滴定

  • KMnO₄ 滴定では硫酸で酸性にする。塩酸は Cl⁻ が KMnO₄ に酸化されるので不可、硝酸は自身が酸化剤なので不可。
  • 指示薬は不要。終点はKMnO₄の赤紫色が消えずにわずかに残った点。
  • ヨウ素滴定ではデンプン水溶液を指示薬に使う（I₂があると青紫色）。
  • 計算：酸化剤の mol × 受け取る e⁻ の数 = 還元剤の mol × 失う e⁻ の数（MnO₄⁻ は5、H₂O₂ は2、(COOH)₂ は2、Fe²⁺ は1）。

金属のイオン化傾向

Li ＞ K ＞ Ca ＞ Na ＞ Mg ＞ Al ＞ Zn ＞ Fe ＞ Ni ＞ Sn ＞ Pb ＞ (H₂) ＞ Cu ＞ Hg ＞ Ag ＞ Pt ＞ Au

語呂：「リッチに 貸そうかな まあ あてにすんな ひどすぎる 借金」

反応する相手 反応する金属 備考

熱水 Mg
高温の水蒸気 Al、Zn、Fe
希塩酸・希硫酸（H⁺） H₂より左の金属 Pbは表面にPbCl₂・PbSO₄ができてほとんど溶けない

  • 金属樹：イオン化傾向の大きい金属を小さい金属のイオンの水溶液に入れると、小さいほうの金属が析出。Zn を CuSO₄ 水溶液に入れると Cu が析出、Cu を AgNO₃ 水溶液に入れると Ag が析出（銀樹）し溶液は青くなる。
  • 空気中で：Li〜Naは常温で速やかに酸化、Mg〜Cu は加熱で酸化、Ag・Pt・Au は酸化されない。

電池

  • イオン化傾向の大きい金属が負極（電子を出す＝酸化される）、小さいほうが正極（電子を受け取る＝還元が起こる）。
  • 電子は導線を負極 → 正極へ流れる（電流は正極 → 負極）。
  • 起電力はイオン化傾向の差が大きいほど大きい。

ダニエル電池　(−) Zn | ZnSO₄aq | CuSO₄aq | Cu (+)

  • 負極：Zn → Zn²⁺ + 2e⁻（Zn板が溶けて軽くなる）
  • 正極：Cu²⁺ + 2e⁻ → Cu（Cu板に銅が析出して重くなる）
  • 素焼き板（セロハン）：2つの水溶液がすぐに混ざるのを防ぎつつ、イオンを通して電気的なつながりを保つ。
  • 長持ちさせるには ZnSO₄ を薄く、CuSO₄ を濃くする。起電力は約1.1 V。

代謝とATP

  • 代謝：生体内の化学反応全体。同化（単純な物質から複雑な物質を合成、エネルギーを吸収：光合成など）と異化（複雑な物質を分解、エネルギーを放出：呼吸など）。
  • ATP（アデノシン三リン酸）＝アデニン（塩基）＋リボース（糖）＋リン酸3個。アデニン＋リボース＝アデノシン。
  • リン酸どうしの結合（高エネルギーリン酸結合）が切れて ATP → ADP＋リン酸 となるときにエネルギーを放出し、生命活動（筋収縮、物質合成、能動輸送、発光など）に使われる。
  • ATPは「エネルギーの通貨」。生物はATPを蓄えておくのではなく、つねに合成と分解を繰り返している。

酵素

  • 主成分はタンパク質。化学反応を促進する生体触媒で、反応の前後で自身は変化しない（くり返し使える）。
  • 基質特異性：酵素ごとに作用する物質（基質）が決まっている。
  • 細胞内（呼吸・光合成の酵素）でも細胞外（消化酵素：アミラーゼ、ペプシン、トリプシン、リパーゼ）でもはたらく。
  • 高温ではタンパク質の立体構造が変化してはたらきを失う。最適温度は35〜40℃付近のものが多い。最適pHは酵素によって異なる（ペプシン約2、だ液アミラーゼ約7、トリプシン約8）。
  • カタラーゼ：2H₂O₂ → 2H₂O＋O₂ を促進（肝臓や植物の細胞に多い）。無機触媒の酸化マンガン(IV)も同じ反応を促進するが、煮沸しても失活しない。

  • 呼吸と燃焼の違い：燃焼は一気に熱と光を出す。呼吸は酵素によって段階的に進み、エネルギーの一部を ATP に蓄える（残りは熱）。

  • 光合成を行う独立栄養生物（植物・藻類・シアノバクテリア）と、他の生物がつくった有機物を取り入れる従属栄養生物（動物・菌類・多くの細菌）。

遺伝子とその働き

DNAの塩基の相補性、細胞周期とDNA量の変化、転写・翻訳の3つが計算・考察問題の土台です。研究史は「誰が・何を使って・何を明らかにしたか」をセットで覚えます。

DNAの構造

  • 構成単位はヌクレオチド＝リン酸＋糖（デオキシリボース）＋塩基。
  • 塩基は A（アデニン）、T（チミン）、G（グアニン）、C（シトシン）の4種類。
  • 2本のヌクレオチド鎖が塩基で結合した二重らせん構造。AとT、GとCが相補的に対合する。
  • 二本鎖DNAでは A = T、G = C（シャルガフの規則）。A + G = T + C = 50%。
  • 遺伝情報は**塩基の並び順（塩基配列）**として保持される。
  • 10塩基対で約3.4 nm（らせん1回転）。

遺伝子・DNA・染色体・ゲノム

  • 遺伝子：DNAのうち、タンパク質のアミノ酸配列などの情報をもつ部分。DNAの全領域が遺伝子ではない（ヒトでは翻訳される部分はゲノムの約1〜2%）。
  • 染色体：真核生物でDNAがヒストンというタンパク質に巻きついて折りたたまれたもの。
  • ゲノム：その生物が生命活動を営むのに必要な最小限の遺伝情報の1セット（配偶子がもつ1組分）。体細胞は父母由来の2セットをもつ。
  • ヒトゲノム：約30億塩基対、遺伝子数約2万個。
  • 同じ個体の体細胞はすべて同じゲノムをもつ（赤血球など核を失った細胞を除く）。

  • 翻訳：mRNAの連続する3塩基（コドン）が1つのアミノ酸を指定する。tRNAがアンチコドンでコドンと対合し、アミノ酸を運ぶ。リボソームでアミノ酸がつながりタンパク質ができる。

遺伝子の発現と細胞の分化

  • 多細胞生物の体細胞はすべて同じゲノムをもつが、細胞ごとに発現する遺伝子が異なることで、異なる形・はたらきをもつ細胞に分化する。
    • すべての細胞で発現：呼吸の酵素など生存に必要な遺伝子。
    • 特定の細胞でのみ発現：インスリン（すい臓ランゲルハンス島B細胞）、クリスタリン（水晶体）、ヘモグロビン（赤血球になる細胞）。
  • だ腺染色体（ユスリカやショウジョウバエの幼虫）：巨大な染色体で、ところどころにパフ（膨らんだ部分）がある。パフでは転写が盛ん（RNA合成）で、パフの位置は発生の時期によって変わる → 時期によって発現する遺伝子が変わる。ピロニン（RNA）で赤桃色に、メチルグリーン（DNA）で青緑色に染まる。
  • 分化した細胞もゲノムをすべて保持していることは、核移植実験や iPS細胞（山中伸弥、体細胞に数個の遺伝子を導入して多能性をもたせた細胞）から示される。

体内環境

体内環境は「何が変化を感知し（受容）→ どこが中枢になり（間脳視床下部）→ 神経とホルモンのどちらで → どの器官がどう応答するか」の流れで整理します。血糖・体温・体液濃度の3つの調節はこの流れで書けるようにします。

体液と恒常性

  • 体液：血液（血管内）、組織液（細胞の周り、血しょうが毛細血管からしみ出たもの）、リンパ液（リンパ管内）。
  • 体液がつくる環境を体内環境という。体内環境を一定の範囲に保つ性質が恒常性（ホメオスタシス）。
  • 組織液の大部分は毛細血管に戻り、一部はリンパ管に入ってリンパ液となる。リンパ管は鎖骨下静脈で血管に合流する。

血液凝固

  1. 血管が傷つくと血小板が集まり、傷口をふさぐ。
  2. 血小板などから放出される凝固因子のはたらきで、血しょう中のフィブリノーゲンからフィブリン（繊維状のタンパク質）ができる。
  3. フィブリンが血球をからめて血ぺいをつくり、出血を止める。
  4. 傷が修復されると、フィブリンが分解されて血ぺいが溶ける（線溶、フィブリン溶解）。

  • 血管内で血液が固まると血栓となり、血流を妨げる（脳梗塞・心筋梗塞の原因）。

酸素の運搬（酸素解離曲線）

  • ヘモグロビンは、O₂濃度（分圧）が高い肺胞で O₂ と結合して酸素ヘモグロビンになり、O₂濃度が低い組織で O₂ を放す。
  • CO₂濃度が高いほど O₂ を放しやすい（曲線が右にずれる）→ 活発に呼吸する組織で多くの O₂ を渡せる。
  • 計算：組織で放出したO₂の割合 =（肺胞での酸素ヘモグロビンの割合 − 組織での割合）÷ 肺胞での割合（生物基礎 計算ドリル参照）。

  • 構造と機能の単位はネフロン（腎単位）＝腎小体（糸球体＋ボーマンのう）＋細尿管（腎細管）。腎臓1個に約100万個。

血糖値の調節

血糖値（血液中のグルコース濃度）は空腹時に約0.1%（100 mg/100 mL）に保たれます。

高血糖のとき

  1. すい臓ランゲルハンス島B細胞が高血糖を直接感知する。視床下部も感知し、副交感神経を通じてB細胞を刺激する。
  2. B細胞からインスリンが分泌される。
  3. 細胞へのグルコースの取り込みと呼吸での消費が促進され、肝臓・筋肉でグリコーゲンの合成が促進される → 血糖値が下がる。

低血糖のとき

  1. 視床下部が低血糖を感知する（A細胞も直接感知する）。

免疫

免疫は「物理的・化学的防御 → 自然免疫 → 獲得免疫」の3段構えです。獲得免疫は**樹状細胞 → ヘルパーT細胞 → キラーT細胞（細胞性免疫）／B細胞（体液性免疫）**の流れを図にして書けるようにします。

物理的・化学的防御（異物の侵入を防ぐ）

防御 内容
皮膚 表面の角質層（死んだ細胞の層）がウイルスなどの侵入を防ぐ
粘膜 粘液で異物をとらえ、気管の繊毛運動で外へ送り出す
化学的防御 涙・だ液・汗のリゾチーム（細菌の細胞壁を分解）、ディフェンシン（細菌の細胞膜を破壊）、胃液の強い酸性、皮膚表面の弱酸性
常在菌 皮膚や腸の常在菌が病原体の増殖を抑える

自然免疫（生まれつき備わる、すばやく非特異的）

  • 食作用：好中球、マクロファージ、樹状細胞が異物を取り込んで分解する。
  • 食細胞は病原体に共通する特徴をトル様受容体（TLR）などで認識する。
  • NK細胞（ナチュラルキラー細胞）：ウイルス感染細胞やがん細胞を直接攻撃する。
  • 炎症：マクロファージなどが出す物質で毛細血管が拡張し、食細胞が感染部位に集まる。発熱・発赤・はれ・痛みが生じる。

獲得免疫（適応免疫：特定の抗原に特異的、記憶をもつ）

リンパ球（T細胞・B細胞）がはたらきます。T細胞は骨髄でつくられ胸腺で成熟、B細胞は骨髄でつくられ骨髄で成熟します。

  1. 樹状細胞が抗原を取り込み、リンパ節へ移動して断片を細胞表面に示す（抗原提示）。
  2. その抗原に合う受容体をもつヘルパーT細胞が活性化し、増殖する。
  3. 細胞性免疫：ヘルパーT細胞の助けでキラーT細胞が活性化・増殖し、感染細胞を直接攻撃して破壊する。ヘルパーT細胞はマクロファージも活性化し食作用を高める。
  4. 体液性免疫：抗原を取り込んで提示したB細胞をヘルパーT細胞が活性化 → B細胞が増殖・分化して**形質細胞（抗体産生細胞）**になり、抗体を血液中に放出する。
  5. 抗体が抗原に特異的に結合（抗原抗体反応）→ 抗原の毒性を弱め、食細胞に取り込まれやすくなる。
  6. 増殖したT細胞・B細胞の一部は記憶細胞として長く残る。
細胞性免疫 体液性免疫
主役 キラーT細胞 B細胞 → 形質細胞 → 抗体
攻撃の方法 感染細胞を直接攻撃 抗体が抗原に結合して無毒化
主な対象 ウイルス感染細胞、がん細胞、移植された他人の組織 細菌、毒素、体液中のウイルス
関連する現象 移植の拒絶反応、ツベルクリン反応 血清療法、アレルギー
  • 抗体は免疫グロブリンというタンパク質。Y字形で、先端の可変部の構造が抗体ごとに異なり、特定の抗原と結合する。
  • 多様なリンパ球の中から、自分自身の成分に反応するものは成熟の過程で除かれたり、はたらきが抑えられたりする（免疫寛容）。

免疫記憶と二次応答

  • 1回目の侵入（一次応答）：抗体ができるまで1週間程度かかり、量も少ない。
  • 2回目の同じ抗原の侵入（二次応答）：記憶細胞がすぐに増殖し、短時間で大量の抗体がつくられる。
  • ひっかけ注意：別の抗原が初めて侵入した場合は、2回目の注射でも一次応答になる。グラフ問題では「どの抗原の2回目か」を必ず確認。

植生と遷移

遷移の原動力は「土壌の形成」と「林床の光が弱くなること」の2つです。陽樹と陰樹の光合成曲線の違いから、なぜ陰樹林が極相になるのかを説明できれば、この単元の考察問題は解けます。

植生と森林の構造

  • 植生：ある地域に生育する植物の集まり。外観（相観）は、最も多く地表をおおう優占種で決まる。
  • 植生は森林・草原・荒原に大別される。
  • 発達した森林の階層構造：高木層 → 亜高木層 → 低木層 → 草本層 → 地表層（コケ植物など）。林冠（最上部）で光の多くが吸収され、林床の明るさは林冠の数%程度になる。
  • 土壌の層：落葉・落枝の層 → 腐植層（落葉が分解された有機物を多く含み、団粒構造で保水性・通気性がよい）→ 岩石が風化した層 → 母岩。

光合成曲線

  • 見かけの光合成速度 = 光合成速度 − 呼吸速度（測定できるのはCO₂吸収速度＝見かけの光合成速度）。
  • 光の強さ0のとき、CO₂放出速度 = 呼吸速度。
  • 光補償点：光合成速度と呼吸速度が等しくなり、見かけの光合成速度が0になる光の強さ。これより弱い光では生育できない。
  • 光飽和点：それ以上光を強くしても光合成速度が増えなくなる光の強さ。
陽生植物（陽樹） 陰生植物（陰樹の幼木を含む）
呼吸速度 大きい 小さい
光補償点 高い 低い（弱い光でも生育できる）
光飽和点 高い 低い
強い光での光合成速度 大きい（速く成長） 小さい
例 ススキ、アカマツ、クロマツ、コナラ、シラカンバ アオキ、ベニシダ、スダジイ、タブノキ、ブナの幼木
  • 同じ個体でも、日なたの葉（陽葉：厚く小さい）と日かげの葉（陰葉：薄く広い）で同様の違いが見られる。

遷移

  • 一次遷移：土壌がない場所（溶岩台地、新しい島）から始まる。長い時間（数百年以上）がかかる。
  • 二次遷移：山火事跡・伐採跡・耕作放棄地など、土壌や種子・地下茎が残っている場所から始まる。一次遷移より速い。

生態系とその保全

生態系の問題は、食物網の中で「ある生物が減ると、直接食べる・食べられる関係にない生物にどう影響するか（間接効果）」を矢印でたどれるかが勝負です。人間活動の影響は用語と具体例をセットで覚えます。

生態系の構成

  • 生態系 = 生物（生物群集）＋ 非生物的環境（光・温度・水・大気・土壌など）。
  • 作用：非生物的環境が生物に影響を与えること（例：光が植物の成長に影響）。環境形成作用：生物が非生物的環境に影響を与えること（例：森林ができて林床が暗くなる、落葉で土壌ができる）。
  • 生産者：光合成などで無機物から有機物をつくる（植物、藻類、シアノバクテリア）。
  • 消費者：生産者がつくった有機物を直接・間接に取り入れる。一次消費者（植物食性動物）、二次消費者（動物食性動物）…。
  • 分解者：遺体や排出物の有機物を無機物に分解する消費者（菌類・細菌）。

食物連鎖・食物網・生態ピラミッド

  • 食べる・食べられるの直線的なつながり＝食物連鎖。実際には複雑な網目状＝食物網。
  • 食物連鎖の各段階＝栄養段階。
  • 栄養段階ごとの個体数や生物量（現存量）を積み上げた図＝生態ピラミッド。一般に上位ほど小さい。
  • ひっかけ注意：個体数ピラミッドは逆転することがある（1本の樹木に多数の昆虫）。

種の多様性と生態系のバランス

  • 間接効果：ある生物が、直接関係しない生物に食物網を通じて影響を及ぼすこと。
  • キーストーン種：食物網の上位にあって、個体数は少なくても生態系のバランスに大きな影響をもつ種。
    • ペインの実験（岩礁海岸）：ヒトデを除去すると、ヒトデに食べられていたイガイ（ムラサキイガイ）が増えて岩場を独占し、フジツボ・カメノテ・藻類などが減って種数が減少した。
    • ラッコ：ラッコが減少 → ウニが増加 → ケルプ（大型の海藻）が食べ尽くされる → ケルプの森にすむ魚などが減少。
  • かく乱：台風・山火事・洪水・伐採など、生態系を変化させる外部からの作用。
  • 生態系は小さなかく乱を受けても元に戻る力（復元力）をもつが、大きなかく乱では元に戻らないことがある。
  • 中程度のかく乱が起こる場所では、多くの種が共存して種の多様性が高くなることがある（中規模かく乱説）。
  • 生物多様性の3つのレベル：遺伝的多様性（同種内の遺伝子の違い）、種多様性、生態系多様性。

物質の循環（概要）

  • 炭素：大気中のCO₂ → 光合成で有機物 → 食物連鎖 → 呼吸・分解でCO₂に戻る。化石燃料の燃焼で大気中のCO₂が増加。
  • 窒素：根粒菌（マメ科植物と共生）、アゾトバクター、一部のシアノバクテリアなどが大気中のN₂をアンモニウムイオンに変える（窒素固定）。植物は土壌中のアンモニウムイオンや硝酸イオンを吸収してタンパク質などをつくる。
  • エネルギーは生態系内を循環せず、最終的に熱として出ていく（物質は循環、エネルギーは流れる）。

問1 対物ミクロメーター（1目盛り10 µm）の10目盛りと接眼ミクロメーターの25目盛りが一致した。(1) 接眼ミクロメーター1目盛りの長さ、(2) 接眼ミクロメーター15目盛り分の細胞の長さ、(3) 対物レンズを10倍から40倍に変えたときの接眼ミクロメーター1目盛りの長さを求めよ。

解答・解説を見る解答・解説

解答(1) 4 µm　(2) 60 µm　(3) 1 µm

(1) 10 × 10 µm ÷ 25 = 4 µm。(2) 15 × 4 = 60 µm。(3) 倍率が4倍になると、1目盛りが示す実際の長さは1/4。

接眼ミクロメーターは接眼レンズに入れるので目盛りの見かけの大きさは変わらず、対物ミクロメーターは試料と一緒に拡大される。

解答・解説を見る解答・解説

解答8 µm/秒

20 × 4 µm = 80 µm を10秒 → 8 µm/秒。

問3 ある二本鎖DNAの塩基のうちAが30%であった。T、G、Cの割合を求めよ。

解答・解説を見る解答・解説

解答T 30%、G 20%、C 20%

A = T = 30%。G + C = 40%、G = C = 20%。

解答・解説を見る解答・解説

解答(1) T 32%、C 25%　(2) 25%

二本鎖の G + C が40%なら、それぞれの鎖でも G + C = 40%、A + T = 60%。鎖Ⅰ：T = 60 − 28 = 32%、C = 40 − 15 = 25%。

鎖Ⅱは鎖Ⅰと相補的なので、鎖ⅡのG = 鎖ⅠのC = 25%。

（二本鎖全体での割合と、片方の鎖での割合を混同しないことが最大のポイント）

解答約2 m

C 細胞周期

問9 細胞周期が20時間の細胞集団から1000個を観察すると、間期900個、前期50個、中期20個、後期10個、終期20個だった。(1) 分裂期、(2) 中期の長さを求めよ。

解答・解説を見る解答・解説

解答(1) 2時間　(2) 0.4時間（24分）

各時期の細胞数の割合は、その時期にかかる時間の割合に等しい（細胞が細胞周期のどの時期にもばらばらに分布している場合）。

分裂期 100/1000 × 20 = 2時間。中期 20/1000 × 20 = 0.4時間。

問10 培養細胞の数が60時間で1.0 × 10⁴個から8.0 × 10⁴個に増えた。細胞周期の長さを求めよ。

解答・解説を見る解答・解説

解答20時間

8倍 = 2³ → 3回分裂。60 ÷ 3 = 20時間。

問11 細胞周期が20時間の細胞集団について、細胞1個あたりのDNA量（G₁期の細胞を2とする）を測定すると、DNA量2の細胞が600個、2より大きく4より小さい細胞が200個、4の細胞が200個だった。分裂期を1時間とするとき、G₁期・S期・G₂期の長さを求めよ。

解答・解説を見る解答・解説

解答G₁期 12時間、S期 4時間、G₂期 3時間

DNA量2 = G₁期：600/1000 × 20 = 12時間。2〜4 = S期：4時間。4 = G₂期＋分裂期：4時間 → G₂期 = 4 − 1 = 3時間。

分裂期の終期で細胞質分裂が終わるまでDNA量は4のまま。

問12 ¹⁵Nだけを含む培地で育てた大腸菌を¹⁴Nだけを含む培地に移して3回分裂させた。DNAを密度で分けたとき、重いDNA（¹⁵N/¹⁵N）・中間のDNA（¹⁵N/¹⁴N）・軽いDNA（¹⁴N/¹⁴N）の比を求めよ。

解答・解説を見る解答・解説

解答重 : 中間 : 軽 = 0 : 1 : 3

分裂のたびにDNA分子数は2倍。もとの¹⁵N鎖2本は消えず、必ず別々の分子に1本ずつ残る → 中間は常に2分子。3回分裂で計8分子 → 中間2、軽い6。

n回分裂後は 中間 : 軽 = 2 : (2ⁿ − 2)。

共通テスト形式演習

生物基礎の共通テストは、対照実験の読み取り・グラフや表の比較・仮説の検証が中心です。オリジナル問題8題、目標時間は全体で25分。「何と何を比べると、何がわかるか」を毎回言葉にしてから選択肢を見てください。

問1酵素の性質（対照実験）

3%過酸化水素水5 mLを入れた試験管A〜Eに、次のものを加えて気泡の発生を調べた。

試験管 加えたもの 結果
A ニワトリの肝臓片 気泡が多く発生
B 煮沸した肝臓片 発生しない
C 酸化マンガン(IV) 気泡が多く発生
D 煮沸した酸化マンガン(IV) 気泡が多く発生
E 石英砂 発生しない

さらに、気泡が出なくなったAに過酸化水素水を追加すると再び気泡が発生したが、肝臓片を追加しても発生しなかった。

考察として適当なものを二つ選べ。

  1. Bで気泡が出なかったのは、煮沸によって肝臓片に含まれていた過酸化水素が失われたためである。
  2. AとBを比べると、肝臓に含まれる反応を促進する物質は、熱によってはたらきを失うことがわかる。
  3. CとDを比べると、酸化マンガン(IV)も高温ではたらきを失うことがわかる。
  4. Eは、A・Cで気泡が出たのが固体を加えた物理的な刺激によるものではないことを確かめるための実験である。
  5. Aで気泡が出なくなったのは、肝臓に含まれる酵素がはたらきを失ったためである。
解答・解説を見る解答・解説

解答②、④

① 過酸化水素は試験管の中の溶液に入っている。肝臓側の物質が失活したと考える。

③ Dでも気泡が出ているので、無機触媒は熱で失活しない。

⑤ 基質（H₂O₂）を追加すると再び反応したので、止まったのは基質がなくなったため。酵素は反応後も変化せずに残っている。

  2. 実験3の結果は、免疫記憶が抗原の種類によらずはたらくことを示している。

③・④ 胸腺がないとT細胞が成熟しない。拒絶反応は主にキラーT細胞による細胞性免疫。

⑤ 同じ系統は遺伝的に同一で、非自己と認識されないので脱落しない。

問8キーストーン種（実験考察）

岩礁海岸の区画から上位捕食者のヒトデを取り除き続け、固着性の生物の種数を調べた。対照区（ヒトデあり）の種数は5年間15種で変わらなかったが、除去区では1年後12種、3年後8種となり、イガイが岩場の大部分を覆った。

適当なものを二つ選べ。

  1. ヒトデはイガイを食べることで、イガイが岩場を独占するのを防いでいた。
  2. ヒトデを除くと種数が減ったのは、ヒトデが他のすべての生物の主な餌だったためである。
  3. この結果は、上位の捕食者が食物網を通じて間接的に種の多様性を保っていることを示す。
  4. 対照区を設けなくても、除去区の結果だけで同じ結論が得られる。

解答①、③

ヒトデのように、個体数が多くなくても生態系のバランスに大きく影響する種をキーストーン種という。
